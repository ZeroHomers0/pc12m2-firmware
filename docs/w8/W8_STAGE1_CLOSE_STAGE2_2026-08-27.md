## 1. SRAM 哨兵：最低 MSP 栈水位

### 1.1 已确认事实

- 栈区 = **0x100027C8（栈底，安全下界）.. 0x100029C8（栈顶，原始 BIN 初始 SP）**，共 512B。
  - 原始 BIN 向量表第 0 项初始 SP = `0x100029C8`（实读 `LPC1765.bin`，2026-08-27）。
  - `FUN_000001c4`（`000001c4_FUN_000001c4.txt`）装载 0x100027C8/0x100029C8 作栈边界；
    `globals.c` `DAT_000001d8=0x100027C8`、`DAT_000001dc=0x100029C8`。
  - 栈区无业务变量（SRAM0 最高业务变量 ~0x1000236C），512B 全部是栈。
- offline `-fstack-usage`：最大单函数静态帧 48B（`output_stage`），不含调用链/中断嵌套，
  必须实机哨兵测量。
- **SWD 限制**：固件复用 P1.30(SWDIO)/P1.29(SWCLK)，运行中无法 halt 读 SP；
  J-Link V9.70 无 `repeat` 循环命令。→ 不能用运行中 MSP 采样。

### 1.2 测量原理（读栈区残留）

1. connect-under-reset 停核（启动代码未跑，.bss 未清）。
2. `ClrRESET` 放行 → 启动代码清 .bss（含栈区 0x100027C8..0x100029C8 → 全 0 基线）。
3. 固件运行 N 秒（TIMER1 LCD 扫描 / TIMER2 / 按键 / 菜单 / Modbus 中断负载）。
4. `SetRESET` 停核（不复位执行，内存保留运行后残留）。
5. `mem32` 读栈区 → 从栈顶往下找**最后一个非 0 字** = 历史最低栈覆写位 ≈ 最低 MSP。
   （启动清零后栈未到区域保持 0；栈活跃/曾到区域残留非 0 运行值。）

### 1.3 执行步骤

```bash
# ① 生成脚本（运行窗口 60s，期间操作面板按键/菜单制造中断负载）
python tools/w8/w8_stack_sentinel.py gen --run-ms 60000 -o w8_sentinel.jlink

# ② 执行（控制电下，板已连 J-Link）
"tools/jlink/JLink.exe" -device LPC1765 -if SWD -speed 4000 \
  -CommanderScript w8_sentinel.jlink > w8_sentinel.log

# ③ 分析
python tools/w8/w8_stack_sentinel.py analyze w8_sentinel.log
```

运行窗口内建议操作：切菜单、调参数、SET/UP/DOWN 各若干次，覆盖 TIMER1 LCD 扫描 +
按键 + 菜单编辑路径；如阶段 3 已备 USB-RS485 可同时触发 Modbus 读写增加负载。

### 1.4 判定

- **PASS**：最低栈覆写位 > 栈底 `0x100027C8` 且余量 ≥ 128B（`w8_stack_sentinel.py` 判定）。
- **FAIL**：水位触底或余量 < 128B → 栈溢出风险，立即停止，评估调用链/中断嵌套。

### 1.5 预期参考

离线静态：最大单函数帧 48B。TIMER1 ISR（LCD 扫描）帧 + 主循环调用链 + 按键，
预计栈深 < 256B（余量 > 256B）。实际以实机为准。

## 2. 继电器误吸合监测

### 2.1 静态结论（2026-08-27 代码确证，低风险）

- 继电器驱动 = **ULN2003A（U29）达林顿阵列，输入高=吸合（高有效）**。
  - P0.22=RLY1 运行、P0.21=RLY2 报警、P0.20=RLY3 备用（HARDWARE_VERIFICATION §三.3）。
- `pin_config`（09_output_stage.c:59，0xE5A8）把 P0.20/21/22 设为输出（FIO0DIR |= 位），
  随后 **FIO0CLR 清 0**（67-69 行）→ 初始输出低电平 = 继电器释放。
- 复位 → `pin_config` 前，P0.20/21/22 为 GPIO 输入高阻 → ULN2003 输入不驱动 → 释放。
- P1.20..23 为状态 LED（输出，非继电器）。
- **结论**：从复位到初始化再到运行，P0.20/21/22 均不产生吸合电平，静态误吸合风险低。

### 2.1b 上电预期表（A/B 差分定论，2026-08-27 追加）

- SYNC_2C(0x1000172C) = 锁机标志（`globals.c` DAT_00000750；**1=放行 / 0=锁机**，
  `README.md` §关键语义澄清）。main() 认证段 `01_startup.c:291` 无条件
  `*DAT_00000750 = 1`（抄板永久放行）→ 上电后恒放行。
  `load_config`（`06_param_system.c:366`）虽在启动时 `SYNC_2C = SYNC_38`，但在 291 行
  **之前**执行；运行中 `param_sync_live_to_eeprom` 仅更新影子 SYNC_38、**不写 SYNC_2C**。
- state_machine 两条吸合路径：
  - 375 行 `if (*RUN != 0) fio0_pin22_ctrl(1)` → RLY1 运行继电器（**设计意图**，运行指示）。
  - 397 行 `if (*SYNC_2C != 1)` → 锁机强制 RLY3/RLY2/RLY1 三继电器全吸合。
- **A/B 差分** `tools/w8/w8_relay_ab.py`（原 BIN 0x458C vs 编译固件 0x45C0，
  hook FIO0SET/CLR 写序列逐 bit 比较，三场景全 PASS）：

  | 场景 | RLY3/P0.20 | RLY2/P0.21 | RLY1/P0.22 |
  |---|---|---|---|
  | 上电放行 SYNC_2C=1 RUN=0 | 断开 | 断开 | 断开 |
  | 锁机 SYNC_2C=0 RUN=0 | 吸合 | 吸合 | 吸合 |
  | 运行态 SYNC_2C=1 RUN=1 | 断开 | 断开 | 吸合 |

- **上电预期**：控制电上电 + 复位期间三继电器全断开、无危险动作；RLY1 仅在用户启动
  （RUN=1）后吸合（属设计行为，非误动作）。若实测出现任意继电器在停机态吸合 → FAIL，
  重点核对 SYNC_2C(0x1000172C) 是否被改写。
- 说明：此前一次 Unicorn 扫描误报"上电恒吸合"，根因是 preset 地址笔误
  （0x10000750 应为 0x1000172C，注释遗留旧地址），已修正并重跑 A/B 全 PASS。

### 2.2 实机确认步骤

1. 控制电上电，万用表/示波器测 P0.20/21/22（或 P6 继电器触点端子）电平。
2. 复现上电瞬间（断电→上电）、以及 J-Link 复位（`SetRESET`→`ClrRESET`）各一次，
   记录三脚电平与任何高电平脉冲宽度（示波器单次触发）。
3. 预期：全程低电平 / 无脉冲。若出现高电平或吸合声 → FAIL，停止评估驱动链。
4. 同时观察 P1.20..23 LED：仅状态指示，异常常亮也记录（不阻塞）。

### 2.3 判定

- **PASS**：上电及复位全程 P0.20/21/22 无高电平脉冲，继电器无吸合。
- **FAIL**：任一继电器误吸合 → 立即停止。

## 3. 阶段 2 启动清单：三相同步与空载触发

前置：§1、§2 全部 PASS。**阶段 2 起仍断市电/门极/功率负载**，但需注入同步信号。

### 3.1 硬件清单

- ≥2 通道示波器（建议 4 通道，同时看 EINT + G1-G6）。
- **三路 120° 隔离同步源**：直接注入 MCU 侧时，先用示波器确认电平始终 0..3.3V
  （严禁超压）。单路输入只允许验证中断响应，**不能判定三相时序**。
- 可选：信号发生器（50/60 Hz 方波）+ 移相器/隔离变压器 组三相同步。

### 3.2 接线与信号

- 三相过零输入：EINT1/2/3 = **P2.11/P2.12/P2.13**（PINSEL4 已配，光耦 U10/U11/U12）。
  - 三相同步 TU/TV/TW：P2.12/TU(U12)、P2.11/TV(U11)、P2.13/TW(U10)。
  - 下降沿触发（`eint1/2/3_init`：EXTPOLAR 清位=下降沿）。
- 触发输出：G1-G6 = **P0.17/P0.15/P0.18、P2.9/P2.19/P2.16**；
  12 脉波扩展 = P2.8/P2.7/P2.6/P2.5、P0.8/P0.7。
  - ⚠️ 2026-08-27 追加（据代码级预案 `W8_STAGE2_CODE_PREPLAN_2026-08-27.md` §2）：**G5=P0.19、
    G6=P0.16**，非 P2.19/P2.16（AGENTS.md 已修正；pin_config/TIMER1 ISR/封锁三处一致）；且 **2-3 判据修正**：
    固件输出为 54μs 载波 @≈9.26kHz + 60° 窗口间隔，无显式 12° 单脉，原"12°=666.7/555.6μs"判据废弃。

### 3.3 验证点（对应 W8_TEST_MASTER §4 阶段 2 的 2-1..2-6）

| # | 验证点 | 判定标准 |
|---|---|---|
| 1 | EINT1/2/3 频率/相序/电平/下降沿 | 50/60Hz、120° 互差、0..3.3V、下降沿触发 |
| 2 | G1-G6 逐路脉宽 | **12°**：50Hz=666.7μs、60Hz=555.6μs |
| 3 | 相邻触发间隔 | **60°**：50Hz=3.333ms、60Hz=2.778ms，相序正确 |
| 4 | 给定变化 → 触发角 | 按 `触发角=180°−当前角` 单调变化 |
| 5 | 停机/急停/过压/过流/缺相 | 及时撤销触发，无残留窄脉冲 |
| 6 | 波形与 TIMER2.MR0/运行/故障状态 | 交叉记录一致 |

### 3.4 判定

- **PASS**：全部波形与保护路径通过。
- **FAIL**：任何一路异常 → 不得进入阶段 3/4。

- TIMER2.MR0 运行值可经 J-Link 读 SRAM 交叉核对（连接方式同 §1.3）。
