## 0. 一句话结论

**TIMER1 ISR 就是 SCR 触发脉冲生成引擎**（240 步扫描 = 360°，6 窗口 × 40 步 = 60° 每窗口）；
**TIMER2 是单次触发角延时**（过零后延时 MR0 → 启动 TIMER1 扫描）；**封锁/安全态 =
`gpio_outputs_set()` 全部触发脚置高**（静态无脉冲）。上电/停机全程触发脚为静态高电平，
**只有满足门控条件才产生触发脉冲**。

`09_output_stage.c` 里 TIMER1 ISR 注释写"LCD 12864 动态扫描"是**反编译误判**
（已由 PROGRESS §4j.E 确证推翻；LCD 实为 P1 口驱动，主循环刷新）。

## 1. 触发输出架构（TIMER2 → TIMER1 触发链）

```
输入过零（TW 下降沿, 每周期一次）──► EINT3_IRQHandler（0xFA2C）
        │  频率识别 / 相序锁存 / 门控判定
        │  有效 → TIMER2.MR0 = 触发角延时（单次）
        ▼  MR0 匹配中断
TIMER2_IRQHandler（0xFF48）：scan=0，启动 TIMER1（MR0=0x36 步进）
        │
        ▼
TIMER1_IRQHandler（0xFF6C）：每步 scan++（0..240），按窗口+mode 对 4 个触发脚 SET(偶)/CLR(奇)
        │  窗口边界（scan=40,80,…,240）→ MR0=1160μs(50Hz)/609μs(60Hz) 长保持
        ▼
scan>240 → scan=0，等下个过零重新编程 TIMER2
```

- **EINT3 = P2.13(TW)**，下降沿，**每周期一次**（50Hz=20ms / 60Hz=16.67ms）——触发时序锚点。
- **EINT1 = P2.11(TV)、EINT2 = P2.12(TU)**：参与**相序自检**（哪个先到 → mode_byte），
  不是触发定时源。
- **TIMER2 单次匹配**（MCR=3，ISR 里 TCR=2 不复载）——只做触发角延时，之后交给 TIMER1。
- **TIMER1 自由扫描 240 步 ≈ 一整周**（6 窗口 × 40 步），同时生成全部 6 个窗口的门极脉冲。

### 时序参数（PCLK=25MHz、PR=0x18=24 → 定时器节拍 1μs）

| 项 | 值 | 电角度（50Hz） | 电角度（60Hz） |
|---|---|---|---|
| 每步（载波） | MR0=0x36 → 54μs | ≈1.5° | ≈1.8° |
| 载波周期 | 2×54=108μs ≈ 9.26kHz | — | — |
| 窗口边界长保持 | MR0=0x488=1160μs / 0x261=609μs | ≈20.9° | ≈13.2° |
| 每窗口 | 40 步 | 60° | 60° |
| 每整周 | 240 步 | 360° | 360° |

## 3. TIMER1 240 步扫描 = 触发脉冲生成机制

每 scan 步按**窗口（40 步=60°）+ mode_byte** 选择 4 个触发脚：**偶 scan SET、奇 scan CLR**
→ 载波 2×54μs=108μs ≈ 9.26kHz，脉宽 54μs。每窗口同时触发 **2 个主门极 + 2 个 12 脉波门极**
（互补相）。

### 触发序列（PROGRESS §4k 全表，已与反编译 C 逐窗口核对一致）

**mode_byte=1**（TU 先到 → 逆相序）：G4,G5 | G6,G5 | G6,G1 | G2,G1 | G2,G3 | G4,G3

| 窗口(scan) | 主门极 | 12 脉波 |
|---|---|---|
| W0 (1-40) | G4, G5 | P12-G4, P12-G3 |
| W1 (41-80) | G6, G5 | P12-G5, P12-G3 |
| W2 (81-120) | G6, G1 | P12-G5, P12-G2 |
| W3 (121-160) | G2, G1 | P12-G6, P12-G2 |
| W4 (161-200) | G2, G3 | P12-G6, P12-G1 |
| W5 (201-240) | G4, G3 | P12-G4, P12-G1 |

**mode_byte=2**（TV 先到 → 正相序）：G1,G6 | G5,G6 | G5,G4 | G3,G4 | G3,G2 | G1,G2

| 窗口(scan) | 主门极 | 12 脉波 |
|---|---|---|
| W0 (1-40) | G1, G6 | P12-G2, P12-G5 |
| W1 (41-80) | G5, G6 | P12-G3, P12-G5 |
| W2 (81-120) | G5, G4 | P12-G3, P12-G4 |
| W3 (121-160) | G3, G4 | P12-G1, P12-G4 |
| W4 (161-200) | G3, G2 | P12-G1, P12-G6 |
| W5 (201-240) | G1, G2 | P12-G2, P12-G6 |

- **每门极在其 2 个相邻窗口触发 = 120° 导通窗口**（如 G1: W2+W3；G4 跨 W5+W0 环绕），
  相邻主门极对 = 三相桥标准触发表，**双脉冲 60° 间隔**。
- **mode1/mode2 互为反相序适配**（相序自检：TU 先到 → mode1；TV 先到 → mode2）。

## 4. 触发角链路（2-4 单调性）

```
output_stage（主循环每 9 拍）：
  0x1000EDB4 = 0xB4 − start_phase         触发角 = 180° − 当前角
  → 软起斜坡（触发步进=(TRIG_PERIOD−角×6333/100)/50/除数）
  → 闭环 PID → g_cl_cached_out → out_setpoint
        │
EINT3_IRQHandler（每次 TW 过零）：
  out_scale = out_setpoint × 系数/10000（50Hz 单相 ×0x58、三相 ×0x80；60Hz 单相 ×0x50、三相 ×0x70）
  TIMER2.MR0 = out_freq_adj×10 + BASE + out_fine×K − out_scale
        │  8 组 BASE×K（50/60Hz × 单/三相 × mode1/2）：
        │    50Hz 单相 0x1800/0x1814、60Hz 单相 0x11D7/0x11EB
        │    50Hz 三相 0x2AB5/0x2AC9、60Hz 三相 0x20AF/0x20B9；K=0x38(50Hz)/0x33(60Hz)
        ▼
触发角延时（越小=越提前触发）→ TIMER2 单次匹配 → 启动 TIMER1 扫描
```

- **out_scale 增大 → MR0 减小 → 触发提前**（导通角增大）→ 输出增大，单调。
- out_freq_adj（菜单 69..688）×10、out_fine（主从偏移 40..160=100±60°）×K 为粗/细相移。
- 触发角随给定变化的单调性 = 2-4 代码级预期依据。

## 5. 封锁/安全态（2-5 保护撤销的核心）★

`gpio_outputs_set()`（0xE79A）= **全部 12 个触发脚置高**（G1-G6 + P12-G1~G6）。

调用点（全部为停机/保护/失锁路径）：
- **EINT3 门控失败**：`input_locked<2 || >7`、`out_param≠0`、`freq_hz<50`（0xFA2C ISR 904 行）
- **50Hz/60Hz 相位保持超时**（phase_cnt 失配累计 >4 → 停机复位，含 out_param|=0x2000）
- **state_machine 停机/急停/联锁**（07_state_machine.c 1208/1224/1236 行）
- **output_stage 停机斜坡/非法态**（09_output_stage.c 697/716/753/767/868/888/904 行）
- **启动路径**：pin_config 同样置高（上电默认全高=封锁）

物理极性：GPIO 高 → HEF40106（反相）→ FR120N → 脉冲变压器 → 门极（有效电平**待实测**，
HARDWARE_VERIFICATION §四.5）。**但无论极性如何，封锁态 = 触发脚静态不翻转 =
无门极脉冲 = SCR 不触发**——这是安全判据（触发只在载波翻转时发生）。

### 保护标志（output_stage，0x1000EDF4，只置不清锁存）

| 位 | 故障 | 判据（×延时） |
|---|---|---|
| bit4 | 过压 | edf0×50 拍 |
| bit5 | 过流 | ee00×50 拍 |
| bit3 | 缺相 | 0.15×/1.5×/2× 多级 ×50/20/10 拍 |
| bit9 | 缺相严重级 | 2.5×/3×/3.5× ×5/2/1 拍 |

## 6. 上机预期表（2-1..2-6 修正版）

### 2-1 EINT1/2/3 频率/相序/电平/下降沿

| 项 | 预期 |
|---|---|
| 引脚 | EINT1=P2.11(TV)、EINT2=P2.12(TU)、EINT3=P2.13(TW) |
| 触发 | 下降沿（EXTPOLAR 清位） |
| 频率识别 | EINT3 每 10 次判 phase_cnt：0x60-0x67→50Hz、0x51-0x55→60Hz（phase_cnt 每 2ms 递增） |
| 相序自检 | TU 先到→mode_byte=1（逆序表）；TV 先到→mode_byte=2（正序表） |
| 门控 | input_locked∈[2,7] && out_param==0 && freq≥50 才编程 TIMER2；否则封锁 |

### 2-2 逐路记录 G1-G6（含 12 脉波扩展）

见 §2 引脚表。**G5=P0.19、G6=P0.16**（P12-G1~G6 = P2.8/2.7/2.6/2.5、P0.8/0.7）。
示波器 4 通道分组：CH1=G1/G2、CH2=G3/G4、CH3=G5/G6、CH4=EINT 参考。

### 2-3 脉宽 / 间隔 / 相序 —— 判据修正 ★

**修正**：原判据"12°=666.7μs / 555.6μs 单脉"**与固件不符**——固件无显式 12° 常量。

| 项 | 固件实际预期 | 说明 |
|---|---|---|
| 载波 | 54μs 脉冲 @ ≈9.26kHz（2×54=108μs） | 偶 SET/奇 CLR，每门极 2 窗口内翻转 |
| 窗口间隔 | 60°：50Hz≈3.33ms / 60Hz≈2.78ms | 窗口边界 MR0=1160/609μs 长保持 |
| 窗口宽 | 60°=40 步 | 每门极 2 窗口=120° 导通窗口 |
| "12°" 等效 | 边界长保持 20.9°@50Hz / 13.2°@60Hz + 载波积分 | 变压器+门极整形后实测核对 |

**实测判定建议**：G1-G6 各脚在各自 2 窗口内出现 54μs 载波翻转、窗口间隔 60°、窗口外
静态高电平；门极/变压器副边有效脉宽实测核对"≈12°"规格（可能是 54μs 载波经
KMB419-301S 积分展宽）。

### 2-4 触发角单调性

| 项 | 预期 |
|---|---|
| 链路 | 给定↑ → out_setpoint↑ → out_scale↑ → MR0↓ → 触发提前 |
| 判据 | 窗口起点相对过零**单调前移**（示波器光标），无回跳/抖动 |

### 2-5 停机/急停/过压/过流/缺相撤销触发

| 触发条件 | 预期行为 |
|---|---|
| 停机/急停/联锁 | gpio_outputs_set()：12 脚全高、无翻转、无残留窄脉冲 |
| 频率失锁 | 相位保持超时（>4 失配）→ 同上 + out_param\|=0x2000 |
| 过压/过流/缺相 | 0x1000EDF4 置位 → state_machine FAULT 分支 → gpio_outputs_set |
| 撤销时间 | 同一 ISR/主循环拍内完成，无逐脚残留 |

### 2-6 波形与 TIMER2.MR0 / 运行状态交叉记录

- TIMER2.MR0 = 0x40090018 运行值（J-Link 读，连接方式同 W8_STAGE1 §1.3）。
- 交叉核对：示波器测得窗口起点延时 ≈ MR0 值 × 1μs（±1 步 54μs 内）；
  `freq_hz`(0x1000FBF4)='2'/'<'、`mode_byte`(0x1000FBE4)、`input_locked`(0x1000FBA8)
  与波形相序/频率档一致。

## 7. 遗留待实测项

1. **门极有效电平极性**：GPIO 高=封锁 的极性推演（HEF40106 反相→FR120N→变压器）需实测
   （HARDWARE_VERIFICATION §四.5）。
2. **"12° 脉宽" 实测核对**：MCU GPIO 是 54μs 载波；门极/变压器副边有效脉宽是否 ≈12°。
3. **TIMER2 MR1（out_div）用途**：EINT3 同时写 TIMER2.MR0+MR1（out_div），MR1 的触发
   语义（可能是脉冲宽/第二事件）未在 ISR 内体现，待波形交叉核对。
4. **EINT3 相位锚定**：TW 下降沿每周期一次（非每 60°），触发扫描整周同步一次——上机时
   确认扫描起点与 TW 边沿对齐。
