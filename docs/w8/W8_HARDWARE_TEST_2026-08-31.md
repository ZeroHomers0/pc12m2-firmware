# PC12M-2 硬件实测规范

> 更新日期：2026-08-31。进度只维护在 `W8_TEST_MASTER.md`。

## 安全前提

- 阶段 0-4 断开市电、高压主回路、SCR 门极和实际负载，只接隔离限流控制电。
- 不确认地参考时禁止用普通示波器探头测量功率侧。
- 任一触发常导通、相序异常、保护不撤销、继电器误动作或异常复位都必须立即断电。

## 空载触发必检

- 三路同步输入 P2.11/P2.12/P2.13 的频率、相位和下降沿。
- 十二路输出 P0.17/P0.18/P0.19/P2.9/P0.16/P0.15/P2.8/P2.7/P2.6/P2.5/P0.8/P0.7。
- 每路脉宽、相邻间隔、完整相序、给定变化的单调性。
- 停机、急停、过压、过流、缺相时十二路全部进入安全态。

所有实测记录至少包含日期、固件 SHA、接线、供电限流、仪器型号、波形文件和结论。
