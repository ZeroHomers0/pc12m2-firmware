# UART3 串行协议逆向报告

> 固件：`LPC1765.bin`（NXP LPC1765 / Cortex-M3）
> 设备：ST33C 变频电源（恒压/恒流/开环三模式，正弦波输出，厂商 SINEP0WER）
> 协议：**Modbus-RTU 变体**（自定义单字节寄存器编址 + 标准 CRC-16 + 功能码 3/6/0x10）

---

## 1. 物理层

| 项 | 值 |
|---|---|
| 外设 | UART3（基址 0x4009C000） |
| TX 引脚 | P0.0（TXD3） |
| RX 引脚 | P0.1（RXD3） |
| 方向控制 | P1.29（FIO1 bit29，RS485 DE/RE，高=发送/低=接收） |
| 波特率 | 可选（`baud_sel` 0..3 + `baud_idx` 表，见 §6） |

初始化 `uart3_init`(0xAC24)：PINSEL0 设 P0.0/P0.1 为 UART3、PCONP 开 UART3 时钟、P1.29 输出低（接收态）、按 `baud_sel` 配 LCR/DLL、FCR=7（开 FIFO）、IER=RDA|THRE。

## 2. 帧格式

```
┌────────┬────────┬──────────────────────┬─────────┬─────────┐
│  addr  │  func  │        data          │ CRC_lo  │ CRC_hi  │
│ 1 字节 │ 1 字节 │      N 字节          │ 1 字节  │ 1 字节  │
└────────┴────────┴──────────────────────┴─────────┴─────────┘
```

- **addr**：从站地址，存于 `0x100016FF`。与请求不匹配 → 丢弃（不应答）。
- **CRC**：CRC-16，初值 0xFFFF，查表实现（两张 256 字节表 @0x11034/0x11134），`FUN_0000af64`(0xAF64)。校验失败 → 异常码 4。
- 传输顺序：数据大端（`value = hi<<8 | lo`），CRC 低字节在前。

### 关键帧字段（data 区约定）

该设备把"寄存器"做成**单字节编号**，且请求里固定带一个 `0x10` 标记：

| 偏移 | 含义 |
|---|---|
| frame[0] | 从站地址 |
| frame[1] | 功能码 3 / 6 / 0x10 |
| frame[2] | 固定 `0x10`（寄存器组标记，读/写都要求 ==0x10） |
| frame[3] | 寄存器号（**1 起始**，内部 -1 变 0 起始） |
| frame[4..5] | 数量 或 数值（16 位大端） |
| frame[6..] | 数据（写多寄存器时） |

> 例：写单寄存器 `frame[1]=6` 时，`frame[3]`=参数号，`frame[4..5]`=值。
> 读 `frame[1]=3` 时，`frame[3]`=起始寄存器，`frame[4..5]`=数量。

## 3. 功能码与响应

| 功能码 | 含义 | 说明 |
|---|---|---|
| 0x03 | 读寄存器 | 读 `start_reg` 起 `n` 个寄存器 |
| 0x06 | 写单寄存器 | 写 1 个参数（带范围校验 + 重配置 + 调 FUN_000035f2） |
| 0x10 | 写多寄存器 | 连续写多个寄存器（**无逐值范围校验**、落点与写单不一致、不调 FUN_000035f2，见 §4d） |
| 其它 | — | 异常码 1（非法功能） |

**异常响应**（`func | 0x80` + 异常码）：

| 异常码 | 含义 |
|---|---|
| 1 | 非法功能码 |
| 2 | 非法寄存器地址（reg==0 或 >0x3F） |
| 3 | 非法数据值（数值越界 / 字节数不符） |
| 4 | CRC 校验错误 |

**0x03 读响应**：`[addr][0x03][byte_cnt=n*2][n × 16位值][CRC]`
**0x06 写响应**：`[addr][0x06][0x10][参数号][值hi][值lo][CRC]`（回显）
**0x10 写响应**：`[addr][0x10][0x10][起始号][数量hi][数量lo][CRC]`

## 5. 接收/发送/分派流程

```
UART3_IRQHandler (0xAF08)
 ├─ IIR==0x04 (RDA) → func_0x0000aed0 (收字节)
 │     tx_active==0 → 置 1，rx_idx=0
 │     读 U3RBR → buf_22a4[rx_idx++]；复位超时计数 0x10001791
 └─ IIR==0x02 (THRE) → 发 tx_buf[tx_idx++]，发完关 THRE、开 RDA、P1.29 转接收

主循环轮询 FUN_0000ae50 (0xAE50)
 └─ tx_active==1 且超时计数>10 → tx_active=5（帧完整），禁 RDA

主循环 → FUN_0000b642 (0xB642，11.5KB 主分派器)
 ├─ tx_active==1 → 返回（未收完）
 ├─ tx_active!=5 → 其它状态处理
 ├─ 校验 addr / func / CRC
 ├─ func==6 → 写单寄存器（~52 个硬编码参数处理，含校验+重配置）
 └─ func==3 → 读寄存器（FUN_0000af94）；func==0x10 → 写多寄存器（FUN_0000b2e0）
```

**发送** `FUN_0000ae0c`(0xAE0C)：P1.29 置高（发送态）→ `tx_active=6` → 等 THRE → 发 tx_buf[0]，其余 IRQ 续发。

## 6. 波特率配置

`uart3_init` 按 `baud_sel`(0x10001704) 选 LCR 与 `baud_idx`(0x10001700) 查 `baud_table`(0x100017BC)：

| baud_sel | LCR | 说明 |
|---|---|---|
| 0 | 0x87 | 8 位 + DLAB（帧格式默认） |
| 1 | 0x8B | 8 位 + 校验位 + DLAB |
| 2 | 0x9B | 8 位 + 校验 + 校验类型 + DLAB |
| 3 | 0x83 | 8 位 + DLAB |

除数 `DLL = PCLK / (baud_table[idx] × {955,950,945,938,925,915}/1000)`，对应约 8 档波特率。

## 8. 如何与设备通信（实测建议）

1. RS485 半双工，接 P0.0/P0.1（若板上有 RS485 收发器）或直接 UART3。
2. 从站地址读 `0x100016FF`（默认值待确认，可能 1）。
3. 例：读模式 + 增益：
   - 读寄存器 1~3：`[01][03][10][01][00][03][CRC_lo][CRC_hi]`
4. 例：写增益 A=2200：`[01][06][10][02][08][98][CRC_lo][CRC_hi]`
5. CRC-16（Modbus 标准，poly 0xA001 反射，init 0xFFFF）。

## 9. 遗留项

> 2026-08-20 更新：以下原遗留项**已解决**（详见 `PROGRESS_2026-08-20.md`）：

- ✅ **从站地址默认值**：无硬编码默认；由芯片 reg 0x64（非易失）开机读回。菜单范围 1..246，Modbus 写允许 0..247。建议实测先试地址 1。
- ✅ **FUN_000035f2 作用**：**参数影子同步器**（61 组 live≠shadow→写芯片），不是"重算输出"。已纠正 i2c_param_sync.md §2。
- ✅ **CRC 多项式**：标准 Modbus CRC-16（poly 0xA001 反射，init 0xFFFF），双 256 表 @0x11034/0x11134，`FUN_0000af64` 查表。
- ✅ **寄存器 4~26 / 41~45 / 51~63 语义**：完整范围+读写落点见 §4 表。关键：reg 24/25 读写不对称、reg 27-29 只写别名、reg 47=从站地址。
- ✅ **regs 40-45 / 51-55 物理含义**（2026-08-20 确证，见 PROGRESS_2026-08-20.md §4b）：
  - **regs 40-45 = 实时测量值**：reg40=ADC ch5（src_value，主屏显示+闭环参考）、reg41/42/43=ADC ch2/ch1/ch0、reg44/45=ADC ch3/ch4（闭环反馈）。
  - **regs 51-55 = ADC 各通道满度标定除数**（ch0→53, ch1→52, ch2→51, ch3→54, ch4→55，范围 3500..4500）。`测量 = (比例×avg×2)/标定除数`。不是输出设定字。
  - 输出级计算见 PROGRESS §4c（FUN_0000e9ac）。

- ✅ **reg 22 / reg 61 / reg 62 语义**（2026-08-20 确证，见 PROGRESS_2026-08-20.md §0 #12）：
  - **reg 22**（0..60）= 菜单第9项设定（编码器 0..60，芯片参数，LPC1765 内部不消费）。
  - **reg 61**（0..100）= **远程输出使能**（P0.20）。写非 0 → `FUN_00010588(1)` → FIO0SET|0x100000；写 0 → FIO0CLR。
  - **reg 62**（<181）= **输出下限系数**（下限=180-值，reg9 为上限）。原"{3,63,63}"为误读：63 来自读多寄存器 reg≤0x3F 校验，3 是异常码。
- ✅ **reg 40 读写不对称**：写 handler(0xD47E) buf[3]==0x28、值≤1000 → src_value(0x10001788)；读侧为 ADC ch5(0x100015A8)。
- ✅ **写多寄存器 0x10**（2026-08-20 确证，见 PROGRESS_2026-08-20.md §4d）：
  - 校验：`start_reg` 1..62、`count` 1..62、`buf[6]==count×2`；**逐寄存器值无范围校验**。
  - 落点与写单不一致：reg24/25→0x1000170E/0F（活动对）、reg40→0x100015A8（ADC ch5）、reg27-32/37/38/44-46→0x100017AC（scratch）。
  - 不调用 FUN_000035f2（写单总是调用）。
- 芯片 reg 0x6E-0x72（0x10001722-26）5 字节参数语义。
