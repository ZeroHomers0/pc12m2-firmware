**设备定位（硬件口径）**：PC6M-10 是**三相晶闸管（SCR）功率控制板**——LPC1765 依据三相同步相位、给定、反馈与保护状态**计算移相触发时刻**，六路 GPIO 经 HEF40106→FR120N→KMB419-301S 脉冲变压器隔离，输出六路晶闸管门极触发脉冲（12° 脉宽、双脉冲 60° 间隔）。支持 6 脉波主桥 + 12 脉波扩展（P11）。**不是"变频输出正弦 PWM"**，是**相控整流的触发角控制**。

## 二、重大修正项（逆向需修正）⚠

### 1. 显示设备：不是 7 段复用数码管，是 12864 图形 LCD
- 逆向："TIMER1_IRQHandler=7 段复用显示，P0.15-19/P0.7/8/P2.5-9 段位"——**错误**。
- 硬件：P0.15-19、P0.7/8、P2.5-9 **是晶闸管触发脉冲输出**（见 §二.2）；LCD 由 **P1 口**（DB0-7=P1.0/1/4/8/9/10/14/15，RS=P1.27，E=P1.28，CS1=P1.25，CS2=P1.26，背光=P1.24）驱动。
- 修正：TIMER1 显示扫描 ISR 驱动 **12864 LCD**（双控制器 KS0107/KS0108，CSA/CSB 左右半屏）。

### 2. P0.15-19 / P0.7-8 / P2.5-9 = SCR 触发脉冲输出（真实功率输出路径）★
| GPIO | 网络 | 驱动链 |
|---|---|---|
| P0.17 | **G1**（主六脉冲） | U39/HEF40106→FR120N→KMB419-301S |
| P0.15 | **G2** | 同上 |
| P0.18 | **G3** | 同上 |
| P2.9 | **G4** | 同上 |
| P0.19 | **G5** | 同上 |
| P0.16 | **G6** | 同上 |
| P2.8 | P12-G1 | U18/HEF40106→P11（12 脉波扩展） |
| P2.7 | P12-G2 | 同上 |
| P2.6 | P12-G3 | 同上 |
| P2.5 | P12-G4 | 同上 |
| P0.8 | P12-G5 | 同上 |
| P0.7 | P12-G6 | 同上 |
- 触发波形：单脉冲宽度 **12° 电角度**（50Hz≈666.7μs / 60Hz≈555.6μs），**双窄脉冲前沿间隔 60° 电角度**（50Hz≈3.333ms / 60Hz≈2.778ms）。
- **修正语义**：`gpio_outputs_set()`（FUN_0000e79a）"置显示段全高"实为**置所有触发输出 GPIO 高**。物理极性待实测（HEF40106 反相 + FR120N + 脉冲变压器，见 §四.5）。
- **TIMER2_MR0 公式**（`out_freq_adj×10+BASE+out_fine×K−out_scale`）= **触发角延时**：从同步过零到触发点的定时；8 组 BASE×K 对应 out_phase(0-3)×工频(50/60Hz) 组合。

### 3. P0.20/21/22 = 继电器驱动（ULN2003A），非"输出使能/停机 GPIO"
| GPIO | 网络 | 功能 |
|---|---|---|
| P0.22 | RLY1（U29/ULN2003A） | **运行输出继电器**（P6-1/2/3） |
| P0.21 | RLY2 | **报警输出继电器**（P6-4/5/6） |
| P0.20 | RLY3 | **备用输出继电器**（P6-7/8/9） |
- 逆向"fio0_pin22_ctrl=P0.22 停机线"→ 修正为 **P0.22=运行继电器，停机链清 P0.22=释放运行继电器**（语义仍自洽）。
- **reg61=远程输出使能→P0.20** 需复核：P0.20 是备用继电器 RLY3。可能 reg61 实际驱动运行继电器路径，或"远程使能"经其他 GPIO；**待确认**（§四.2）。

### 4. P1.20-23 = 状态 LED，非功率级控制线
| GPIO | 指示 |
|---|---|
| P1.20 | 恒压 LED20A（翠绿） |
| P1.21 | 恒流 LED18B（翠绿） |
| P1.22 | **运行 LED19C**（翠绿，=逆向 fio1_pin22_ctrl，停机清 P1.22=运行灯灭，语义自洽） |
| P1.23 | 故障 LED17D（高亮红） |
- 恒压/恒流/故障 LED 与逆向 gain_sel 模式、out_param 故障位吻合。

### 5. P2.1-2.4 = ADuM1201 隔离串行链路（认证通道）
- U25=ADuM1201ARZ：P2.4(A 输入 VIA)、P2.2(A 输出 VOA)、P2.1(B 输入 VIB)、P2.3(B 输出 VOB)，构成 **MCU↔隔离侧全双工串行**。
- 修正：认证是**经隔离器的双通道串行挑战-应答**（2 根输入 2 根输出），不是 3 根直接 GPIO 连芯片。远程端器件未在本次文档中明确（见 §四.3）。
- **U5≠认证芯片**：U5 是 ADM2483BRWZ 隔离 RS485 模块（J2=RXD/RE&DE/TXD/AVCC/AGND，J1=A/B/电源）。报告明确"U5不是单颗未知器件，而是一块隔离RS485小PCB"。

### 6. P4.28/29 = 空脚（逆向 pin_config 曾把 P4.28/29 配为输出清零——硬件为未用，无实际影响）。

## 四、待用户/实测确认项

1. **TIMER2.MR0 触发角 → 12° 脉冲波形的生成机制** — **【2026-08-20 固件已破解，PROGRESS §4k】**：TIMER2 单次匹配中断（触发角延时到点）→ TIMER2_IRQHandler 置 scan=0 并启动 TIMER1；**TIMER1_IRQHandler（0xFF6C，非显示扫描）逐 scan 步（0..240，6 窗口×40 步=360°）对触发 GPIO 做偶 SET/奇 CLR（4 引脚/步，mode1/mode2 两组序列）**。窗口=60°=双脉冲间隔 ✓；载波 54μs 步（≈9.26kHz）；窗口边界（scan=40,80,...）MR0=1160μs(50Hz)/609μs(60Hz) 长导通 ≈ 12°-21° 单宽触发——**12° 脉宽由载波+变压器积分/边界长导通实现，固件无显式 12° 常量**。固件机制完整，**仍建议示波器实测**验证：①脉宽实际值；②触发输出极性（gpio_outputs_set 置高=封锁 or 触发）。
2. **reg61=远程输出使能的实际引脚**：P0.20 硬件是备用继电器 RLY3；reg61 与运行继电器 RLY1(P0.22) 或运行使能的对应关系待确认。
3. **ADuM1201 隔离链路远程端器件**：认证对象是隔离侧的具体芯片/模块（U5 已排除=RS485；可能是功率侧定制 IC 或 P11 扩展板），待原理图细节/实物。
4. **P0.9 24V 交流方波的用途**：报告与逆向均未最终确定（缺相检测/工频基准/同步补充）。
5. **触发输出极性**：GPIO 高电平经 HEF40106 反相→FR120N→脉冲变压器后，门极有效电平待实测；`gpio_outputs_set()` 置高是否为"封锁/安全态"需结合极性确认。
6. **reg44/reg45 = Uf / IF 的具体顺序** — **【2026-08-20 固件已确证，PROGRESS §4b】**：FUN_00001fbc 反编译（AD0CR SEL 顺序 ch2→ch1→ch0→ch5→ch3→ch4）：**reg44=ch3=AD0.3=IF 输出电流反馈、reg45=ch4=AD0.4=Uf 输出电压反馈**。完整映射：reg40=Ug(AD0.5)、reg41=IA(AD0.2)、reg42=IB(AD0.1)、reg43=IC(AD0.0)。仍可 Modbus 实测标定复核。

### B. 印证结论（全部命中 + 细化）
