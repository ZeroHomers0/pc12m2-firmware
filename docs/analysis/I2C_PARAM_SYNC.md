# I2C 参数系统逆向报告 — 芯片 @0x53 与影子同步

> 固件：`LPC1765.bin`（LPC1765 / Cortex-M3）
> 设备：ST33C 变频电源（恒压/恒流/开环，SINEP0WER）
> 恢复时间：2026-08-20（死机后重建会话）
> 关联文档：[[uart3_protocol.md]]、[[state_machine_analysis.md]]、[[PLAN.md]]、[[PROGRESS_2026-08-20.md]]

---

## 0. 一句话结论

**I2C 从机 @0x53 = 24C02 类被动串行 EEPROM（256 字节，纯参数非易失存储）**，不是功率控制芯片（§4g.A 确证：`i2c_read_reg` 全部 130+ 调用点都在开机 `load_config`，运行期从不读回）。
LPC1765 在 RAM 里维护一套"实时参数"和一套"影子镜像"，当实时参数变化时，通过
`FUN_000035f2` 把新值推送到 EEPROM；开机时通过 `load_config` 把 EEPROM 里的全部参数读回 RAM。
**功率输出由独立于 LPC1765 的外部功率电路产生**（§4f：无本地 PWM/DAC；§4g：EEPROM 被动、P2.1-2.3 另有防克隆认证芯片）。

```
┌────────────┐  RS485/Modbus   ┌─────────────────────────┐  I2C @0x53   ┌──────────────────┐
│  上位机    │◄───────────────►│ LPC1765 (UART3)         │◄────────────►│ EEPROM@0x53     │
└────────────┘                 │  · RAM实时参数 0x100016xx │   参数存储    │ 24C02 类 256字节 │
  旋转编码器 ──────────────────►│  · RAM影子镜像 0x10001664..│              └──────────────────┘
  按键/菜单  ──────────────────►│  · 同步器 FUN_000035f2    │
                               │  · 认证 P2.1-2.3 → 认证芯片│
                               │  · 使能 P0.20/停机 P0.21/22 → 外部功率电路
                               └─────────────────────────┘
```

## 1. 关键函数

| 地址 | 名 | 作用 |
|---|---|---|
| 0x35F2 | `FUN_000035f2` (改名建议 **param_sync_i2c**) | 运行时同步：61 组参数，live≠shadow 时写芯片 |
| 0x25DC | `load_config` | 开机加载/初始化芯片参数（双银行校验 + 银行选择） |
| 0x1E88 | `i2c_write_reg` | 写 1 字节到芯片 reg：`[0xA6][reg][val]` + STOP |
| 0x1EBC | `i2c_read_reg` | 读 1 字节：`[0xA6][reg]` → `[0xA7]` 读回 |
| 0x1C40 | `i2c_gpio_init` | I2C 引脚初始化：`FIO0DIR|=0x400|0x800`、`FIO0SET|=0x400|0x800` |
| 0x1CAE / 0x1CFE | `i2c_start` / `i2c_stop` | 起始/停止条件 |
| 0x1D3C | `i2c_write_byte` | 写 1 字节（MSB 先行 + ACK 读回） |
| 0x1DFA | `i2c_read_byte` | 读 1 字节 |
| 0x1C82 | `i2c_delay` | 位时钟延时 |

**⚠️ I2C 是 GPIO 位带模拟（bit-banged），非硬件 I2C0**（固件无 0x4001C000 引用，见 PROGRESS §4f）：
- **SDA = P0.10**（FIO0 bit10 = 0x400，FIO0SET/CLR/PIN 操作）
- **SCL = P0.11**（FIO0 bit11 = 0x800）

**I2C 器件地址**：`0xA6`（写）/ `0xA7`（读）→ 7-bit 地址 **0x53**。
- `i2c_write_reg(value, reg)`：写器件 `0xA6` → 发 reg → 发 value → STOP → delay(5)
- `i2c_read_reg(&val, reg)`：写器件 `0xA6` → 发 reg → 重启 START → 写 `0xA7` → 读 1 字节 → STOP → delay(2)

## 2. FUN_000035f2 — 参数影子同步器（核心机制）

对每一组参数执行：

```c
if (live != shadow) {           // 实时值 ≠ 影子镜像？
    shadow = live;              // 更新影子
    i2c_write_reg(shadow>>8, reg);    // 高字节 → reg
    i2c_write_reg(shadow & 0xFF, reg+1); // 低字节 → reg+1（word 型参数）
}
```

- **byte 型参数**：写 1 个寄存器
- **word 型参数**：写 2 个连续寄存器（高字节在前 reg，低字节在 reg+1）

被调用点：`main`(0x652)、`state_machine`（12 处）、`FUN_0000b642`（Modbus 写后约 60 处）、`FUN_00010820`。

> ⚠️ **纠正先前结论**：uart3_protocol.md §9 曾推测 FUN_000035f2 是"重算输出"。
> 实际它**只做同步推送**，不重算任何数值。0x53 是被动 EEPROM（§4g.A），输出由外部功率电路产生。

## 3. load_config — 开机加载（双银行校验 + 初始化）

```
读 reg 5, reg 6 → 若 (reg5=='U') || (reg6=='U')  [0x55 = 已初始化标记]
   └─ 是 → 银行 A 有效：读回 reg 0x0A..0x9C 全部参数 → 影子RAM → 拷贝到 live RAM
读 reg 7, reg 8 → 若 (reg7=='f') || (reg8=='f')  [0x66 = 第二银行标记]
   └─ 是 → 银行 B 有效：读回 reg 0x1F..0xBF → 影子RAM → 拷贝到 live RAM
否则（芯片空/未初始化）
   └─ 把 RAM 默认值 → 写往芯片全部寄存器，写 0x55 到 reg 5/6，写 0x66 到 reg 7/8
```

**结论**：芯片是**非易失存储**。寄存器 0x55/0x66 是软件初始化标记（magic bytes），不是数据。

**银行选择（参数组 1..4）**：
```
cfg_1710 (0x10001710, Modbus reg 23) ∈ {1,2,3,4}   ← 活动参数组
  组1 → 活动增益 = 0x10001711, 0x10001712
  组2 → 活动增益 = 0x10001713, 0x10001714
  组3 → 活动增益 = 0x10001715, 0x10001716
  组4 → 活动增益 = 0x10001717, 0x10001718
  活动增益拷贝到 0x1000170E / 0x1000170F  (Modbus reg 24/25)
```

> 即 Modbus 寄存器 23 选择 4 组参数之一，每组含 2 个增益系数；
> 寄存器 24/25 总是反映"当前活动组"的增益。

## 5. 从站地址专题（slave_addr，0x100016FF）

- **存储**：live RAM 0x100016FF，影子 0x10001706，芯片 reg 0x64（非易失）
- **开机**：从芯片 reg 0x64 读回 → 影子 → 拷贝到 live
- **菜单设置**（state_machine 地址设置屏）：
  - 编码器正转（r4=0x2/0x16）：`slave_addr = min(slave_addr+1, 246)`   （0x88D0–0x88E6）
  - 编码器反转（r4=0x3/0x21）：`slave_addr = max(slave_addr-1, 1)`   （0x8948–0x8958）
  - **范围 1..246**
- **Modbus 匹配**（FUN_0000b642 @0xB66A–0xB674）：`frame[0] == slave_addr`，**无广播地址(0)处理**，不匹配即丢弃
- **默认值**：代码内无硬编码默认。首次上电若芯片空 → 把 RAM 当前值写芯片。
  因此出厂地址 = 工厂烧写的芯片 reg 0x64 值。**建议实测先试地址 1**。

## 6. 与 Modbus 寄存器表的区别（重要）

Modbus 寄存器号（1..63）**≠** 芯片物理寄存器号（0x0A..0xBF）。

```
Modbus 写 reg N ──► 写 RAM live 变量 ──► FUN_000035f2 ──► 写芯片物理 reg ──► 功率输出
Modbus 读 reg N ◄── 读 RAM live 变量 ◄── load_config 开机读芯片 ◄── 芯片存储
```

- Modbus 空间是"逻辑参数表"，芯片空间是"物理寄存器表"，两套编号由 RAM 地址桥接。
- Modbus 写单寄存器范围校验后调用 FUN_000035f2 同步到芯片（见 uart3_protocol.md §4）。
- 运行时间计数（reg 0x97-0x9C）也是持久化的，芯片断电不丢。

- **同步表 61 组全部验证**（从 FUN_000035f2 反编译 + bin 直读字面量池）：完整 live↔shadow↔chip-reg 映射见 PROGRESS §2。

- **reg61 / reg62 语义确证**：芯片 reg 0x24/0x25（0x1000165C）= **远程输出使能**（写非 0→P0.20 高，0→低，FUN_00010588/FIO0SET/CLR）；芯片 reg 0x26/0x27（0x10001660）= **输出下限系数**（FUN_0000e9ac 中 0x10002004=180-值，reg9 为上限）。"reg62 特殊值{3,63,63}"为误读，已纠正。
- **reg40 读写不对称**：写侧是 0x10001788（src_value，Modbus 远程显示源值，≤1000），与读侧 0x100015A8（ADC ch5 测量）不同。

- **闭环链确证**：FUN_00010f0a（门控包装）→ FUN_000108b0（分区选增益 + 积分滤波，输出 0x10002130 钳位 [0x5CC60,0x116520]）→ 缓存 0x1000212C 返回 → out_setpoint。FUN_0000f9aa 为启停预设。

## 8. 相关调用关系

```
main(0x5CC)
 ├─ load_config()                      开机读/初始化 EEPROM@0x53 参数（130+ 次 i2c_read_reg）
 ├─ 若 (0x10002138==0 && 0x10001734<3) → FUN_000106a0() 认证（P2.1-2.3 挑战-应答）
 │    └─ FUN_000035f2()                同步参数到 EEPROM
 ├─ FUN_0000427c()  /  FUN_00010820()  认证重试（最多5次）
 ├─ 若认证失败 (0x100020e9) → 错误屏 + wd_feed() 死循环【锁机】
 └─ 主循环（认证通过才进入）:
     ├─ state_machine(输入) → 菜单/编码器 → 改 live 参数 → FUN_000035f2()
     ├─ FUN_00001fbc() → ADC0 采样
     ├─ FUN_0000e9ac() → 闭环计算 + 使能/停机 GPIO
     ├─ FUN_0000ae50()  → UART3 收帧轮询
     └─ FUN_0000b642(0) → Modbus 分派 → 写 live → FUN_000035f2()
```
