## 0. 菜单系统架构

- **一级菜单 8 项**（`_disp_manual.txt`）：基本参数/保护参数/通讯参数/恢复出厂/PID参数/相位参数/运行时间/版本
- 屏幕索引寄存器：`0x10001745`（二级菜单项索引，各菜单内复用）
- 一级菜单选择：`0x10001744`；菜单门控：`0x10001746`（==1 允许编辑）
- 编辑状态分发（state_machine 中 `r4`）：
  - `r4==2` 单步 +1；`r4==0x16` 快进 +5（阈值类，对应"按住不放快速调"）
  - `r4==3` 单步 -1；`r4==0x21` 快进 -5（阈值类）
  - `r4==1` UP 键（菜单导航/密码输入）；`r4==4` SET 确认/退出
- 每次编辑先写 `0x10001764`=0（清编辑标志），改完 `0x10001778`=0xFA(250) 倒计时返回

## 1. 基本参数菜单（16 屏，0x10001745=0..0xf）

> 手册仅列 12 项；**固件有 16 项**。前 12 项与手册逐一对齐；**13-16 为手册未列的高级/隐藏项**。

**确证证据**：编辑区 0x6DA8-0x6FC6（r4=2/0x16 单步 +1、池 0x70D4-0x7110）+ 0x7114-0x7440（r4=0x16 快进 +5、池 0x7518-0x7554）。两个池区指向**同一组 RAM**，互为印证。

**⚠️ 旧标修正**：
- `gain_a`(0x1000163C) 旧标"增益系数A" → 实为**电压量程**（屏1，≤6000V）
- `gain_b`(0x10001638) 旧标"增益系数B" → 实为**电流量程**（屏2，≤6000A）
- `out_fine`(0x10001654) 旧标"输出微调" → 实为**主从偏移**（屏10，100±60）
- `reg62`(0x10001660) 旧标"输出下限系数" → 菜单标签=**16起始相位**（屏15）。两者同一参数：FUN_0000e9ac 中 `0x10002004 = 180 - 值` 作输出下限（起始相位角），reg9 作上限。**以菜单标签"起始相位"为准，输出下限是其在输出级的作用**。

## 6. 恢复出厂设置

- **入口**：一级菜单==3（0x10001744==3）
- **密码**：UP×6（手册：连续按UP三次+DOWN三次；恢复出厂=UPUPUPUPUPUP）
- **动作**：密码通过 → 写 0x10001764=0 → 置 0x10001745=0 → `bl 0x35F2`（参数同步 live→芯片）→ `bl 0x992`（刷新）→ 重启控制系统
- 字符串池：0x6BD0 区（恢复出厂提示）

**证据**：0x69D6-0x6C3A。0x6BCC=0x10001746（密码门控）、0x6BC8=0x10001764。
