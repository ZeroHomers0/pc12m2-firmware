# PC12M-2 硬件与引脚证据状态

> 整理日期：2026-08-31。本文只记录十二相固件能够证明的事实。

## 已由十二相反汇编确认

- MCU：LPC1765FBD100；Flash 256 KiB。
- 三相同步输入：EINT1/2/3 = P2.11/P2.12/P2.13，下降沿。
- 十二路触发输出：P0.17、P0.18、P0.19、P2.9、P0.16、P0.15、
  P2.8、P2.7、P2.6、P2.5、P0.8、P0.7。
- `gpio_outputs_set@0xE4FA` 将十二路统一置为安全态；P5 已核对 12 次写迹。
- TIMER1 负责十二相触发序列；P5 已通过 972 个矩阵用例。
- P0.22 为运行继电器控制，P1.22 为触发/运行指示。
- UART3、ADC 和 SWD 相关复用以十二相 `pin_config@0xE308` 为准。
