## 二、Modbus 远程通信（上位机 / PLC / 组态软件）

### 2.1 协议参数（已确证）

| 项 | 值 |
|---|---|
| 接口 | UART3 = RS485（ADM2483 隔离模块 U5） |
| 帧格式 | Modbus-RTU `[addr][func][数据][CRC16]` |
| 功能码 | 0x03 读寄存器 / 0x06 写单寄存器 / 0x10 写多寄存器 |
| CRC-16 | poly 0xA001 反射、init 0xFFFF（双 256 查表） |
| 从站地址 | 通讯菜单"1.通讯地址"（RAM 0x100016FF），范围 1..246；Modbus 写允许 0..247；精确匹配、无广播 |
| 波特率 | 通讯菜单"2.波特率" 0..7 档查表（表基址 0x100017BC） |
| 校验位 | 通讯菜单"3.校验位" 0..3（无/奇/偶/1-stop） |

⚠️ **通讯检测**：通讯菜单"4.通讯检测"（0..1）与 RS485 收发有关，改参后需重启生效。

### 2.2 常用寄存器速查（高度确证项）

| Modbus reg | 方向 | 含义 | 备注 |
|---|---|---|---|
| 40 | 读 | **Ug 给定**（AD0.5 实际测量） | 面板给定值；写后回读=注入值（见下） |
| 40 | 写 | 远程给定源值（src_value，≤1000） | **读写不对称**：写是"远程注入"，读是"实测" |
| 41 / 42 / 43 | 读 | **IA / IB / IC 三相电流**（AD0.2/0.1/0.0） | 经 1W 0.1R 采样 + 运放调理 |
| 44 | 读 | **IF 输出电流反馈**（AD0.3） | 保护对象之一 |
| 45 | 读 | **Uf 输出电压反馈**（AD0.4） | 保护对象之一 |
| 61 | 写 | 远程输出使能（→P0.20 备用继电器） | 值 0=低 / 非 0=高 |
| 62 | 读写 | **起始相位/输出下限**（≤180，输出路径 180-值） | 与基本菜单屏 15 同一参数 |
| 24 / 25 | 读写 | **读写不对称**：写→组4 增益槽；读→活动增益对 | 见 §2.3 |

> 完整 63 项寄存器见 `../history/PROGRESS_2026-08-20.md` §4b + 读表 FUN_0000af94。

### 2.3 读写不对称陷阱（易踩坑）

1. **reg40**：读=ADC ch5 实测（Ug），写=远程给定注入（src_value）。→ 想"读回我写的值"看不到，想读真实电压读 reg40 返回的是实测值。
2. **reg24/25**：写落点是"组4 增益槽"（随 EEPROM 同步），读返回"活动增益对"（仅本地计算用，不同步芯片）。→ 写后回读 ≠ 写的值。
3. **reg27-29 只写别名**：读恒 0，写→与 reg51-53 相同 RAM。reg37 只写。
4. **写多 0x10 ≠ 写单 0x06**：0x10 无逐值范围校验，落点不同（部分落到 scratch 0x100017AC 无实际效果），且不触发参数同步。→ **远程改参数请用 0x06 写单**，0x10 慎用。

### 2.4 常见操作示例

- **读实时电压/电流**：0x03 读 reg45（Uf）、reg44（IF）、reg41-43（IA/IB/IC）。
- **远程设给定**：0x06 写 reg40 = 目标值（≤1000）。需配合控制方式（sub_state）为"通讯/定值"。
- **远程启停/输出使能**：reg61 写非 0 使能输出（→P0.20）。⚠️ 硬件 P0.20=备用继电器 RLY3，语义待实测（§四/§五）。
- **修改任意菜单参数**：用 0x06 写对应 reg → 固件自动写回 EEPROM（param_sync）。

## 四、故障诊断手册（症状 → 排查）

### 4.1 保护/报警标志（0x1000EDF4 位标志）

| 位 | 含义 | 说明 |
|---|---|---|
| bit4 (0x10) | 过压 | 输出超过过压保护阈值 |
| bit5 (0x20) | 过流 | 电流超限 |
| bit3 (0x08) | 缺相 | 0xEE04 判据×0.15/1.5/2 且 0xEE10 延时×50/20/10 拍（2026-08-21 复核） |
| bit9 (0x200) | 缺相严重级 | 判据×2.5/3/3.5 且延时×5/2/1（更快触发） |

> 0x1000EDF4 只置不清锁存（需断电复位）。触发后走停机链（P0.22 运行继电器释放 + 停机斜坡）。

### 4.2 指示灯 / 继电器状态（P1 口 / P0 口）

| 引脚 | 指示 | 状态含义 |
|---|---|---|
| P1.20 | 恒压 LED（翠绿） | gain_sel=恒压 亮 |
| P1.21 | 恒流 LED（翠绿） | gain_sel=恒流 亮 |
| P1.22 | **运行 LED**（翠绿） | 运行亮；停机清 P1.22 |
| P1.23 | 故障 LED（高亮红） | 故障亮 |
| P0.22 | RLY1 运行继电器（P6-1/2/3） | 运行吸合 |
| P0.21 | RLY2 报警继电器（P6-4/5/6） | 报警吸合 |
| P0.20 | RLY3 备用继电器（P6-7/8/9） | reg61 远程使能 |

### 4.3 常见症状排查流程

**① 面板无显示 / LCD 花屏**
- 查 12864 LCD 驱动：P1.25/26=CS1/CS2、P1.27=RS、P1.28=E、P1.0/1/4/8/9/10/14/15=DB0-7、P1.24=背光。
- 用示波器确认 TIMER1 扫描时序存在（无则 MCU 未运行/晶振停振）。

**② 开机锁机 / 认证失败（挑战-应答不过）**
- 认证：P2.1(出)/P2.2(入)/P2.3(时钟)/P2.4(复位) 经 ADuM1201 隔离，24 位挑战/16 位应答，失败重试 5 次锁机。
- 检查：隔离侧外部模块是否在位、排针连接（DC3 2×13P/2×5P）是否松动、ADuM1201 供电是否正常。

**③ 某一路触发不输出（如 G2 无脉冲）**
- 触发 GPIO 表（§五.2）→ 先用示波器测 MCU 引脚有无脉冲；有→查驱动级（HEF40106 反相器→FR120N→KMB419-301S 脉冲变压器→晶闸管门极）；无→固件触发序列问题。

**④ 误报警 / 保护乱跳**
- 看报警对象：过压/欠压比 reg45(Uf)；IF 过载比 reg44(IF)；CT 过载比三相电流。
- 确认量程/阈值钳位关系正确（§三.2），三相平衡百分比是否设置过小。

**⑤ Modbus 通讯不上**
- 查从站地址（reg47/菜单通讯地址）、波特率、校验位是否与主站一致；RS485 A/B 线、ADM2483 隔离模块供电；通讯检测开关（§三.3）。

### 5.3 换 EEPROM / 恢复参数注意事项

- 61 组参数存于 AT24C02C，双银行 magic 校验（'U'=0x55 银行 A / 'f'=0x66 银行 B），开机加载。
- 换新 EEPROM 后参数全默认，**建议先完整读出旧芯片参数备份**（可用 I2C 工具 + 本项目的 61 组同步表映射）。
- 参数损坏可能导致开机异常——双银行机制本身有容错，但仍建议定期备份。

## 六、行为定制（改参数级，不用重烧固件）

以下改动通过面板或 Modbus 改参数即可生效，固件逻辑已确证：

| 想改什么 | 改哪 | 说明 |
|---|---|---|
| 软起/软停时间 | 基本屏 7/8（0x1000164C/4D，≤200） | 软起动相位 0→4→5 |
| 触发角/输出上限 | 基本屏 9 相位限制（0x10001650，≤180）+ 屏 15 起始相位（0x10001660） | 输出路径：上限=reg9，下限=180-起始相位 |
| 主从偏移（12 脉波） | 基本屏 10（0x10001654，40..160=±60°） | 参与触发角公式 out_fine×K |
| 保护阈值 | 保护屏 0-7 | 过压/欠压/IF/CT + 时间 |
| PID 响应 | PID 屏 0-3（档）+ 隐藏屏 4-8（误差分区增益） | 档=低速/中速/快速/自定；隐藏项=闭环误差分区选增益 |
| 控制方式 | 基本屏 11（本地/通讯/定值） | 决定 reg40 远程注入是否生效 |
| 远程输出使能 | reg61（→P0.20） | 值非 0=使能 |

> 这些是"改参数"级别。若想改**逻辑本身**（如保护策略、触发算法、通讯协议），需要重烧固件——见 §七。

## 八、硬件实测验证清单（W8，依据 `evidence/hardware/` BOM 表）

> 硬件依据统一归档于 `evidence/hardware/`。芯片级印证已完成（BOM 表 → HARDWARE_VERIFICATION §六）。

固件结论是静态证据，最终靠实测闭环：

1. **触发脉冲实测**（示波器）：测 G1-G6 触发引脚，验证 12° 脉宽 / 60° 双脉冲间隔（50Hz≈3.333ms / 60Hz≈2.778ms）；确认 `gpio_outputs_set()` 置高=封锁还是触发（极性）。
2. **ADC 标定核对**（Modbus）：读 reg40-45，对照实际电压/电流，核对 5 个标定除数（regs 51-55，3500..4500）与工程单位。
3. **认证链路验证**：断开/接回隔离侧模块，确认锁机与恢复行为；确认 reg44=IF / reg45=Uf 顺序。
4. **reg61→P0.20 语义确认**：P0.20 硬件是备用继电器 RLY3，reg61"远程输出使能"与运行继电器 RLY1 的对应关系待实测。
5. **P0.9 24V 交流方波用途**：确认是否缺相/工频基准（固件频率监测用 TIMER0 计数）。
