# PC12M-2 应用与维护指南

> 整理日期：2026-08-31。

本工程用于十二相原固件保全、逆向分析、可编译重建、离线等价验证和后续分级实机验证。

维护顺序：

1. 先读 `AGENTS.md` 和 `docs/project/PROJECT_STATUS.md`。
2. 功能问题从 `firmware/src/` 定位，再回到十二相逐函数反汇编取证。
3. 修改后运行相关静态检查和完整 A/B 验证。
4. 只有 P5 全部通过、备份闭环和固件哈希冻结后，才进入 W8。

模块：启动、LCD、输入消抖、I2C、ADC、参数、菜单状态机、UART3/Modbus、输出级、
继电器/LED、认证、闭环和 GPIO 初始化。

当前工程仍处在离线等价性收尾阶段，不是可直接烧写或带载的发布固件。
